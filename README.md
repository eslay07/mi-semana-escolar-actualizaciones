# Mi Semana Escolar — actualizaciones

Creada por Jimmy Toapanta.

Este repositorio contiene únicamente las descargas de la APK Android firmada y su manifiesto de actualización. El código fuente se conserva en un repositorio privado. No contiene fotos, datos familiares, cuentas ni claves privadas.

Descarga la APK desde Releases. Android solicitará confirmar la instalación; instala encima de la versión anterior conservando los datos.

Manifiesto estable: https://github.com/eslay07/mi-semana-escolar-actualizaciones/releases/latest/download/update.json
